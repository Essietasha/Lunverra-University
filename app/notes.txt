    When we run a Python file directly in terminal/shell e.g python admin.py, Python sets the special variable __name__ to "__main__".
    But when we import that file somewhere else e.g import admin/helpers, the __name__ is set to the module's name "admin" not "__main__".
    This means the code in the file only runs directly/automcly if the file's name is set to main with _name_ = _main_. If not, the code in such files will not run autom except if explicitly called.
    
    So when you write: if __name__ == "__main__": This means “Run the code here only if this file is run directly, not if it’s imported.”

//db.relationship and Backrefs
    NOTE: Before you can use a backref (or any kind of relationship) between two tables, there must be a foreign key in
    one table pointing to the other. The foreign key is what tells the database how these two tables are connected.
    E.g in Application Table: regNum = db.Column(db.String(10), db.ForeignKey('user.regNum))

    user = db.relationship('User', backref='applications')
    db.relationship() tells the system how things are related in the db. 
    For example, an application belongs to one user, and a user can have many applications. 
    By writing user = db.relationship('User', backref='applications'), 're telling the app:
    "Let me easily jump from an application to the user who submitted it":
            application = Application.query.get(1)  # Gets the application with id=1
            print(application.user)  # Get the user who submitted that application
            print(application.user.name)  # Get the user object

    and also 
    "Let me get all the applications a user has":
            user = User.query.filter_by(id=userID)
            print(user.applications)  # List of all Application objects with that user id.

    THIS: applications in backref has an "s" at the end because one user can submit many of them, 
    it’s like saying "user.applications" should give m a list, not just one thing. 
    This setup saves one from writing complicated database queries every time.
